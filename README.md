# Навигатор по нормативке в области ИИ и защиты данных

Навигатор по нормативным актам в области ИИ и защиты персональных данных (152-ФЗ, GDPR, AI Act). Интерфейс включает каталог документов, тематический поиск, сценарии навигации, сравнение и сохранённые карточки. Бэкенд принимает вопрос, находит нужные фрагменты в корпусе (собственный BM25) и формирует ответ с цитатами через LLM; если в документах ответа нет, система отказывает.

## Запуск

Только интерфейс: откройте `app/index.html` в браузере или запустите простой локальный сервер из корня проекта:

```bash
python3 -m http.server 4173 -d app
```

Полный запуск с API, поиском и ответами LLM, из корня проекта:

```bash
pip install -r requirements.txt
uvicorn app.server:app --port 4173
```

Затем перейдите на `http://localhost:4173`. Сервер отдаёт интерфейс и `POST /api/search`.

По умолчанию работают заглушки поиска и LLM. Настоящий режим включается переменными окружения (PowerShell):

```powershell
$env:RAG_SEARCH = "real"
$env:RAG_MIN_SCORE = "3.0"
$env:LLM_BASE_URL = "https://openrouter.ai/api/v1"
$env:LLM_MODEL = "nvidia/nemotron-3.5-super-vl:free"
$env:LLM_API_KEY = "<ключ провайдера>"
```

| Переменная | Назначение | По умолчанию |
|---|---|---|
| `RAG_SEARCH` | `stub` (заглушка) или `real` (BM25 по корпусу) | `stub` |
| `RAG_K` | число фрагментов, передаваемых в ответ | 5 |
| `RAG_MIN_SCORE` | порог отказа: ниже него ответ не формируется | 3.0 |
| `LLM_BASE_URL` | адрес API провайдера; без него работает заглушка LLM | не задан |
| `LLM_MODEL` | идентификатор модели | не задан |
| `LLM_API_KEY` | ключ провайдера; хранить только в окружении, не в репозитории | не задан |

## Проверка

Тесты (запускать в окне, где переменные окружения не заданы):

```bash
python -m pytest
```

Бенчмарк поиска и ответов (10 обычных вопросов и 5 ловушек; метрики Recall@5, MRR, Accuracy и Correct Rejection Rate). Для ответов нужны переменные `LLM_*`:

```bash
python -m benchmark --answers --name <имя прогона>
```

Параметры экспериментов, ручная разметка Accuracy и результаты описаны в `benchmark/README.md`.

## Структура

- `app/index.html` — семантическая разметка приложения.
- `app/styles.css` — визуальная система и адаптивные состояния.
- `app/app.js` — навигация, тематический поиск по каталогу документов, фильтры и сохранённые карточки.
- `app/server.py` — API `POST /api/search`, порог отказа, раздача интерфейса.
- `app/answer.py` — сборка запроса к LLM и проверка ответа и цитат.
- `app/search.py` — поиск BM25 по корпусу; `app/search_stub.py` — заглушка поиска.
- `corpus/` — корпус из 30 фрагментов 152-ФЗ, GDPR и AI Act и скрипт его сборки.
- `benchmark/` — вопросы, метрики, скрипт прогона и результаты.
- `tests/` — автоматические тесты.
- `spec/product.md` — описание продукта, пользователя, объёма и принципов прототипа.
- `spec/product/scenarios.md` — основные пользовательские сценарии первой версии.
- `spec/tech/architecture.md`, `spec/tech/rag.md` — архитектура и описание RAG.
- `CHANGE_HISTORY.md` — журнал изменений.

Карточки законов ведут на тексты 152-ФЗ на сайте Минтруда, GDPR и AI Act в EUR-Lex.
