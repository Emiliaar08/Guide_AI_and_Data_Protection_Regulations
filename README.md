# Навигатор по нормативке в области ИИ и защиты данных

Фронтенд навигатора по нормативным актам в области ИИ и защиты персональных данных. Интерфейс включает каталог 152-ФЗ, GDPR и AI Act, тематический поиск по сведениям об этих документах, сценарии навигации, сравнение и сохранённые карточки.

## Запуск

Откройте `app/index.html` в браузере или запустите простой локальный сервер из корня проекта:

```bash
python3 -m http.server 4173 -d app
```

Затем перейдите на `http://localhost:4173`.

## Структура

- `app/index.html` — семантическая разметка приложения.
- `app/styles.css` — визуальная система и адаптивные состояния.
- `app/app.js` — навигация, тематический поиск по каталогу документов, фильтры и сохранённые карточки.
- `spec/product.md` — описание продукта, пользователя, объёма и принципов прототипа.
- `spec/product/scenarios.md` — основные пользовательские сценарии первой версии.

Карточки законов ведут на тексты 152-ФЗ на сайте Минтруда, GDPR и AI Act в EUR-Lex.
