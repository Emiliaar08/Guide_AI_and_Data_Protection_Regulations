## 19.11.2026 — API `POST /api/search` на заглушках
- Что изменено:
  - `app/server.py`: FastAPI-сервер. `POST /api/search` принимает `query` и `jurisdiction` (`ru`, `eu` или `null`) и возвращает `status`, `answer`, `clarification_question`, `citations` по контракту из `architecture.md`. Тот же сервер раздаёт интерфейс из `app/`, кроме исходников `.py`. Функция `run_search` содержит весь путь запроса и пригодится для benchmark. Настройки через переменные окружения: `RAG_K` (5), `RAG_MIN_SCORE` (1.0), `RAG_SEARCH` (`stub` или `real`).
  - `app/answer.py`: сборка контекста и сообщений для LLM, заглушка вызова LLM, проверка цитат, хук `needs_clarification`.
  - `app/search_stub.py`: заглушка поиска на четырёх тестовых фрагментах (152-ФЗ, GDPR, AI Act), с фильтром по юрисдикции. Настоящий поиск будет в `app/search.py`.
  - `tests/test_api.py`, `requirements.txt`, `pytest.ini`, `app/__init__.py`, `.gitignore`.
  - `spec/tech/architecture.md`: добавлен раздел «Правила API», обновлены «Запуск» и «Проверка».
- Зачем: интерфейс, поиск и LLM подключаются к фиксированному контракту и разрабатываются в разных ветках независимо; поиск и LLM сейчас заменены заглушками с тем же интерфейсом, подмена на настоящие делается в одном месте.
- Решения:
  - Статус `insufficient` возвращается, если поиск ничего не нашёл, если балл лучшего фрагмента ниже `MIN_SCORE`, а также если ответ LLM не ссылается ни на один найденный фрагмент. LLM в первых двух случаях не вызывается.
  - Цитаты собираются из найденных фрагментов, а не из текста модели; ссылки на несуществующие `id` отбрасываются.
  - К полям цитаты добавлено `id`, чтобы интерфейс мог связать метки вида `[D01]` в ответе с карточками источников.
  - Статус `need_clarification` реализован как механизм: при вопросе от `answer.needs_clarification` LLM не вызывается. Само правило пока не определено (открытый вопрос в `rag.md`), поэтому сейчас статус не возникает.
  - Контракт поиска `search(query, jurisdiction, k)` предложен мной и требует согласования с ответственной за RAG.
- Проверка:
  - `python -m pytest`: 12 passed (три статуса ответа, фильтр по юрисдикции, проверка цитат, отказ без вызова LLM, ошибки 422 и 502, раздача интерфейса без исходников `.py`).
  - Вручную: запущен `uvicorn app.server:app --port 4173`, запрос через `Invoke-RestMethod` с вопросом про согласие на обработку вернул `status: ok` с цитатой `D01`.
- Не сделано: настоящий BM25 (`app/search.py`), реальная LLM и ключ, правило для `need_clarification`, значение `MIN_SCORE` по результатам benchmark, вызов API из интерфейса, `corpus/`, benchmark, обновление `README.md`.
